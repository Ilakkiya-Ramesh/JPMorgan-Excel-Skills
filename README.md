# 📈 JPMorgan Chase & Co. – Excel Skills

## 📌 Project Overview

This project is based on the **JPMorgan Chase & Co. Excel Skills Job Simulation** completed through Forage in June 2024.

The simulation focused on using Microsoft Excel for data cleansing, data manipulation, analysis, visualization, and automation.

---

## 🎯 Project Objective

The objective of the simulation was to develop practical Excel skills and use data analysis and visualization techniques to communicate useful information effectively.

---

## 🔍 Project Work

During the simulation, I:

- Performed data cleansing and manipulation
- Applied conditional formatting
- Worked with Excel macros and VBA
- Developed two functional macros integrated with buttons using account sales data
- Created charts and interactive dashboards
- Used Excel and PowerPoint for data visualization and storytelling
